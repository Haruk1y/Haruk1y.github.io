PrompDojo is a realtime multiplayer prompt quiz powered by Gemini.

- Awarded 3rd place out of 70 teams at Gemini 3 Tokyo Hackathon
- Built with Next.js (App Router, TypeScript), Firebase, and Gemini API
- Developed round-based gameplay, realtime ranking, and score feedback loops
- Project demo: <https://gemini-hackathon-bay.vercel.app>
- Hackathon gallery: <https://cerebralvalley.ai/e/gemini-3-tokyo-hackathon/hackathon/gallery>
