# Haruk1y.github.io

Haruki Yajima’s [personal website](https://haruk1y.github.io/), based on [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io).

Edit the introduction, news and publications in `_pages/about.md`, the CV entries in `_data/resume.json`, and the profile links in `_config.yml`.

To preview locally with Ruby 3.3, run `bundle install` and `bin/dev-local`.
